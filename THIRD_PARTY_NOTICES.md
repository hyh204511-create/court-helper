# Third-party notices

court-helper 0.2.0 uses open-source packages distributed under their respective licenses. The authoritative package names and versions are recorded in `package-lock.json` and the OCR `requirements.txt` included with the delivery.

Key runtime components include Node.js, Fastify, PostgreSQL, Nginx, ExcelJS, html2canvas, argon2, pg and ddddocr. Docker images retain their upstream notices. This summary does not replace the license files shipped by each dependency or container image.

No third-party package may be used to upload court credentials, case data or screenshots to a public service. The ddddocr integration runs only on the customer's Windows loopback interface.
