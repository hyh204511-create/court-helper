# 规格：平台账号 Excel 导入

## 目标

在后台“平台账号”页面提供一次性导入 Excel 的能力，导入结果与逐条填写“显示标签、平台账号、平台密码”后保存一致。

## 输入

- 仅接受 `.xlsx`，只读取 `Sheet1`。
- 第 1 行必须包含 A-D 列标题：`原告`、`被告`、`账号`、`密码`；被告仅用于兼容模板，不写入平台账号。
- 从第 2 行开始读取：A 列原告作为显示标签，C 列作为平台账号，D 列作为平台密码。
- 完全空行跳过；标签、账号或密码任一为空的行跳过并返回行号原因。
- 单次最多 2000 行；超过上限拒绝整份文件。

## 行为

- 仅管理员后台会话可调用；使用 multipart 上传，不把凭据放入 URL、日志、响应或浏览器持久化状态。
- 每个有效行调用与单条创建相同的加密保存逻辑，默认启用。
- 标签已存在时跳过该行，不覆盖原账号密码；其它行继续处理。
- 返回 `{ imported, skipped, reasons[] }`，`reasons` 仅含行号和稳定错误码，不含账号、密码或原告明文。
- 原有单条新增、编辑、启停、软删除流程保持不变。

## 范围外

- 不修改原始 Excel。
- 不导入被告或案件数据。
- 不支持多工作表、CSV、批量覆盖或批量删除。

## 删除后重导入闭环

- 平台账号删除保持软删除，历史案件和任务仍引用旧记录。
- 标签唯一性只约束未删除记录；同标签存在未删除账号时仍逐行跳过。
- 软删除后再次导入相同“原告”标签时，必须创建新的启用账号并使用新账号密码，不能被旧记录判为重复。
