# 规格：panel-module（网页浮动面板）

> 版本：0.2 ｜ 状态：已确认、待真实验收 ｜ 依据：Phase 11 后台控制台唯一入口决策、app-module、browser-command-module

## 1. 目标

在法院诉讼服务网（`https://zxfw.court.gov.cn/*`）页面右下角注入**折叠式状态面板**：默认收起为悬浮球，点击后仅展示脱敏登录态、服务器同步状态、统一任务进度和人工接管提示。所有登录、导入、查询和导出操作统一从 `/admin/browser-control` 发起；本面板不构成第二套业务入口。

## 2. 布局与交互

```
默认（收起）：右下角悬浮球（48px 圆钮，含插件图标/缩写 + 登录状态色点）
点击悬浮球 → 展开面板（420px 宽，max-height 82vh，右下角 fixed，Shadow DOM 隔离）
```

面板结构（自上而下）：

```
┌────────────────────────────────────────┐
│ 法院立案/强执查询助手    [状态点 未登录] [−]│  ← 头部：标题 + 登录状态（脱敏账号）+ 收起
│ ─────────────────────────────────────── │
│ 业务操作请前往后台控制台                   │  ← 唯一入口提示
│ 批量任务进度: [████████░░ 12/50]         │  ← 进度区
│ 待处理: 账号A(3条) 账号B(2条)             │
│ ─────────────────────────────────────── │
│ 后台命令驱动 · 未知状态标记待人工           │  ← 底部说明
└────────────────────────────────────────┘
```

- 悬浮球始终可见（`position:fixed; right:16px; bottom:16px; z-index:2147483647`）。
- 点击悬浮球展开面板；点「−」或再次点悬浮球收起；收起时面板不占用页面空间。
- 面板与悬浮球使用 Shadow DOM（`mode:"closed"`）隔离样式，宿主 `all:initial`，不受平台 CSS 污染，也不污染平台页面。

## 3. 面板内容与行为

### 3.1 登录状态
- 复用 `login-detector.js` 的 `detectLoginState` / `getCurrentAccount`：已登录显示状态点绿色 + 脱敏账号（只显示首尾，如 `a***3`）；未登录显示灰色「未登录」。
- 会话失效/过期 → 状态点红色 + 「已过期，请重新登录」，面板不阻塞（批量执行器自行暂停，见 app-module §4.3）。

### 3.1.1 MutationObserver 兜底
- 面板初始化后监听 `document.documentElement`（document_start 阶段 body 可能尚未创建，html 元素恒存在），配置 `{ childList: true, subtree: true }`，用于兜底捕获用户区晚渲染或会话失效导致的 DOM 增删。
- 观察回调读取 `getCurrentAccount(document)`；账号快照未变化时忽略，变化时更新快照并防抖 300ms，触发一次 `refreshPanelLogin()`。
- 页面触发 `pagehide` 时断开观察器并清理未执行的防抖定时器；不监听属性/文本变化，不增加额外轮询。
- 验收：用户区节点新增、删除分别能触发一次刷新；相同快照或 300ms 内连续变更不产生多余刷新；`pagehide` 后观察器和待执行刷新均停止。

### 3.2 唯一入口提示

- 面板固定显示“业务操作请前往后台控制台”；不得出现登录、导入模板、开始查询、导出报表、暂停或继续按钮。
- 扩展执行器继续响应由 SW 下发的统一 browser command，但网页脚本和面板本身都不能创建命令。

### 3.3 进度区
- 监听 content script 批量执行进度：`START_BATCH` 启动后，通过 `chrome.runtime` 消息或 IndexedDB 轮询（≥3s 间隔）刷新「已完成/总数」与当前账号分组。
- 显示待处理分组：按账号聚合未完成条目（脱敏账号 + 条数）。
- 面板收起时不中断任务；重新展开时恢复最新进度。

### 3.4 状态输入

- content 仅向面板传入经过白名单和脱敏处理的登录态、进度、同步摘要及稳定错误码。
- 状态读取失败/超时 → 面板显示“采集器未就绪，请刷新页面”，不猜测状态，也不提供本地业务操作兜底。

## 4. 安全与脱敏
- 面板任何位置不展示完整账号、案号、当事人全名、身份证号、密码、驳回原因或截图；账号只显示首尾各 1 位 + `***`。
- 不触发自动登录、不存凭据；自动登录仅由后台控制台创建的 `LOGIN` 命令驱动。
- 未知状态一律显示「待人工」，禁止面板自行猜测状态词。
- 面板不修改平台请求参数、不做额外轮询（进度刷新间隔 ≥3s）。

## 5. 实现位置
- 新增 `extension/content/court-panel.js`（面板渲染/交互，纯 DOM + Shadow DOM，可测）。
- `court-content.js` 在 `document_start` 后挂载面板（同三客一危模式：`document.documentElement.appendChild(host)`，`DOMContentLoaded` 兜底）。
- esbuild 构建命令追加 `court-panel.js` 到 content bundle（`--format=iife`）。

## 6. 测试
- 单测（jsdom）：
  - 面板挂载：宿主元素存在、Shadow DOM 内结构完整（头部/唯一入口提示/进度区/底部），且无业务操作按钮。
  - 折叠交互：初始为悬浮球；点击展开；点「−」收起；再次点击恢复。
  - 登录状态渲染：未登录/已登录（脱敏断言）/过期三态。
  - 进度渲染：`done/total`、分组文本和同步安全摘要断言。
  - 脱敏：账号 `abcdef` → `a***f`；面板 DOM 中不出现完整账号。
- 真实联调（验收闸门）：由后台控制台创建脱敏测试任务，真实会话中展开面板，只观察登录态、进度和人工接管提示；确认面板无业务操作入口。验收记录只写脱敏摘要。

## 7. 范围外（不做）
- 不做面板内登录表单/验证码处理、导入、查询、导出、暂停或继续操作。
- 不做面板内案件详情展示（详情在平台页，插件只采集）。
- 不做通知中心/声音提醒。
- 不常驻展开（默认收起，避免遮挡政务页面）。
