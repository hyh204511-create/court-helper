# 法院立案/强执查询助手

## 普通用户安装与每日使用手册

版本：0.2.0
后台地址：`https://court.hyhbrand.xyz`
适用环境：Windows 10/11、Microsoft Edge

> 安全提醒：只在客户授权的法院账号和案件范围内使用。未知状态必须交给人工，不要自行改写或猜测。

## 1. 安装前准备

- 已安装 Microsoft Edge，并可正常访问人民法院在线服务网站。
- 已收到交付包中的 `extension` 和 `ocr-helper` 文件夹。
- 已取得后台系统用户名；平台账号由管理员统一维护。
- 电脑时间和时区正确，网络可访问 `court.hyhbrand.xyz`。

## 2. 安装本地 OCR 助手

1. 右键 `ocr-helper/install.ps1`，选择“使用 PowerShell 运行”。
2. 安装器会在当前用户的 `%LOCALAPPDATA%\CourtHelper\ocr-helper` 建立独立环境，并注册登录后启动。
3. 运行 `ocr-helper/health.ps1`。
4. 看到“OCR 助手运行正常：127.0.0.1:8765”即完成。

> OCR 只识别登录验证码，只监听本机回环地址，不读取或保存平台账号文件。OCR 失败时系统会要求人工处理，不会无限重试。

## 3. 安装 Edge 扩展

1. 在 Edge 地址栏输入 `edge://extensions`。
2. 打开左侧“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择交付包中的 `extension` 文件夹。
4. 确认扩展名称为“法院立案/强执查询助手”。
5. 把扩展 ID 与交付清单中的固定 ID 对照；不一致时停止安装并联系管理员。
6. 将扩展固定到工具栏。

## 4. 首次设备配对

1. 点击扩展图标；未授权设备会打开 Setup 页面。
2. 后台地址应自动显示 `https://court.hyhbrand.xyz`，无需手工改成其他地址。
3. 点击“请求后台授权”，记下页面显示的六位核对码。
4. 请管理员登录后台，在“扩展设备”区域核对设备和六码后批准。
5. Setup 显示“设备已授权”后，再次点击扩展图标，应打开后台控制台。

> 六位核对码不是密码。不要把后台密码、法院账号密码或验证码截图发给他人。

## 5. 每日工作流程

1. 打开 `https://court.hyhbrand.xyz` 并登录后台。
2. 在“导入批次”上传当天的 Excel 模板，确认立案/强执行数摘要。
3. 打开人民法院在线服务网站并保持该标签页可用。
4. 在“浏览器控制台”选择平台账号，创建“一键登录”任务；验证码识别失败时按提示人工完成登录。
5. 创建立案查询或强执查询任务。每批最多 50 条，每案自动间隔 3–8 秒。
6. 观察后台任务状态和法院页面右下角状态面板；提示切换账号或人工接管时立即处理。
7. 查询完成后创建“导出报表”任务。
8. 检查本地下载文件，并在后台“报表导出”再次下载一份核对。

## 6. 状态含义

| 显示状态 | 含义 | 操作 |
|---|---|---|
| 审核中 | 平台显示待审核 | 等待后续查询 |
| 立案成功 | 已取得立案成功证据 | 核对案号、日期和截图 |
| 强执成功 | 已取得执行成功证据 | 核对强执案号、日期和截图 |
| 已驳回 | 已取得审核时间、意见和截图 | 按业务流程处理 |
| UNKNOWN / 待人工 | 页面文本未知、结构冲突或证据不足 | 人工查看，禁止猜测 |

## 7. 脱敏操作示例

示例批次只使用“测试账号-A、示例原告甲、示例被告乙”。任务显示成功只代表命令执行完成，案件最终状态必须以案件列表中的明确字段为准。

## 8. 下班前检查

- [ ] 没有仍处于 `pending` 或 `executing` 的任务。
- [ ] 所有 `UNKNOWN`、失败和待人工记录已登记。
- [ ] 导出的 Excel 能正常打开，图片和日期位置正确。
- [ ] 不把包含真实业务数据的 Excel、截图或日志上传到公共网盘或聊天群。
- [ ] 使用完毕后退出后台账号。

## 9. 卸载

1. 在 `edge://extensions` 移除扩展。
2. 运行 `ocr-helper/uninstall.ps1`；脚本只删除本项目计划任务和 `%LOCALAPPDATA%\CourtHelper\ocr-helper`。
3. 如需撤销服务器授权，请管理员同时删除对应扩展设备。
