# Windows 本地版安装与使用

## 安装

1. 双击 `court-helper-windows-x64-setup.exe`，允许一次管理员权限确认。
2. 设置法院查询助手管理员密码；安装程序会自动安装本地后台、数据库和 OCR，不需要另外安装 Node.js、Python 或 PostgreSQL。
3. 安装完成后，按向导提示打开 Edge 的扩展管理页，打开“开发人员模式”，选择安装目录中的 `extension` 文件夹。
4. 点击“诊断与修复”，确认后台和 OCR 均显示正常，再打开“法院查询助手”。

## 日常使用

从桌面快捷方式进入本地控制台，登录后按现有流程导入 Excel、配对扩展、创建查询任务和导出报表。法院账号密码仍只在自动登录所需的内存链路中使用，不写入安装包或日志。

## 故障处理

- 控制台打不开：运行“诊断与修复”，检查 Court Helper Backend 服务。
- OCR 不可用：运行“诊断与修复”；登录自动化失败时按提示转人工，不循环重试。
- Edge 扩展未出现：确认扩展管理页已开启开发人员模式并重新选择 `extension` 文件夹。
- 卸载默认保留业务数据和备份；只有明确选择“同时永久删除本地数据”才会删除 `%ProgramData%\CourtHelper`。
