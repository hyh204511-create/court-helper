# 法院立案/强执查询助手

## 常见故障处理手册

版本：0.2.0

> 先保护数据，再排查。不要在工单中粘贴真实案号、当事人、密码、驳回原因、截图、Cookie、Token 或 `.env`。

## 1. 快速分流

| 现象 | 首要检查 | 安全处理 |
|---|---|---|
| 后台打不开 | DNS、443、防火墙、证书、容器 | 运维检查 `/health` |
| 扩展只能打开 Setup | 地址、设备授权、Token 是否过期 | 重新请求六码并由管理员批准 |
| OCR 不可用 | `health.ps1`、8765 端口、Python 环境 | 重启 OCR；仍失败则人工登录 |
| 登录失败 | 法院登录页、验证码、debugger 权限 | 只重试 1 次，随后人工接管 |
| 查询任务不动 | 后台健康、法院标签页、任务状态 | 保留任务与 outbox，不伪报成功 |
| 状态 UNKNOWN | 页面文本/结构未知或证据冲突 | 人工核对，禁止猜测 |
| Excel 上传失败 | 文件类型、大小、模板结构 | 使用原始模板重新导出 |
| 报表无截图 | 截图上传 ACK、浏览器权限 | 核对案件详情与失败状态 |

## 2. 后台不可访问

运维执行：

```bash
Resolve-DnsName court.hyhbrand.xyz
curl -I https://court.hyhbrand.xyz
docker compose --profile tls ps
docker compose logs --tail=100 app nginx
```

- `/health` 为 503：检查 PostgreSQL 和私有存储，不要继续采集。
- 证书错误：核对 SAN、完整证书链和系统时间。
- 只 HTTP 可达：检查 Nginx TLS 容器和 443 防火墙。

## 3. 设备无法授权

- 确认 Setup 地址精确为 `https://court.hyhbrand.xyz`。
- 确认扩展 ID 与交付清单一致；不一致时移除并从正式 `extension` 文件夹重装。
- 六码过期时重新点击请求授权；不要重复批准旧请求。
- 设备已撤销时，管理员删除旧设备后重新发起配对。

## 4. OCR 或自动登录失败

```powershell
powershell -ExecutionPolicy Bypass -File .\ocr-helper\health.ps1
powershell -ExecutionPolicy Bypass -File .\ocr-helper\start.ps1
```

- 8765 被其他程序占用：停止未知进程，确认只保留本项目 OCR。
- 提示缺少 ddddocr：重新运行安装器。
- 验证码识别错误：系统最多刷新重试 1 次；随后人工输入，禁止循环。
- Edge 显示调试附加失败：关闭其他调试工具，刷新法院标签页；仍失败则人工登录。

## 5. 查询与状态异常

- `SELECTOR_CHANGED`：法院页面可能改版，立即停止批量任务并联系维护人员。
- `UNKNOWN_STATUS_CONFLICT`：API 与可见页面状态冲突，人工核对，不修改映射表。
- `AUTH_REQUIRED`：后台或法院会话失效，重新登录后明确重试。
- `DEPENDENCY_UNAVAILABLE`：后台依赖不可用，保留 outbox，恢复后人工重试。
- 单案失败不会阻塞整批；失败重试 1 次后应进入待人工。

## 6. Excel 问题

- 仅上传 `.xlsx`，单文件不超过 20 MiB。
- 使用规定的双表模板，不要合并或改名关键列。
- 导出后用 Excel/WPS 打开，核对两表区域、日期、案号和图片锚点。
- 报表下载哈希不一致时停止分发，重新下载并联系运维。

## 7. 提交支持信息

可以提交：发生时间、操作步骤、页面名称、任务 ID、request ID、稳定错误码、浏览器/扩展版本、是否可复现。

不得提交：完整 URL 查询参数、请求/响应体、真实业务字段、账号密码、Token、Cookie、证书或密钥。截图必须先确认不含业务明文并按客户制度传递。
